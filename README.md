# 🏫 Smart Campus

Smart Campus is a web-based complaint management system designed to help students report campus-related problems and allow administrators to manage and track complaints efficiently.

## 🚀 Live Demo

👉 [Open Smart Campus](https://smart-campus-ksod.onrender.com)

## ✨ Features

- 📝 Students can submit complaints
- 🆔 Automatic complaint ID generation
- 📋 Students can view submitted complaints
- 🔐 Admin login system
- 📊 Admin dashboard
- 🔄 Update complaint status
- 💾 SQLite database for storing complaints
- 📱 Responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub
- Render
